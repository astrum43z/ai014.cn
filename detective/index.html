● 不用安装 · 无需登录 · 文件本地处理

使用顺序看域名 → 核对来源 → 再行动

不提供“绝对安全”结论。凡是催转账、索要验证码或要求远程控制的消息，先停下来，通过你已知的官方渠道核实。

粘贴整段分享文案

不用先删掉中文。一次提取最多 20 个网址，看清链接实际指向的主机名，不访问目标网页。

不要粘贴密码、验证码、登录令牌、身份证或私人聊天记录。只需与链接有关的那一段。

短链接看不到最终去向

抖音、小红书、B站等分享短链会跳转。本工具不联网展开，看到熟悉的短链域名，也不能确认最终内容安全。

“https://品牌名.其他域名.com”中的品牌文字，可能只是子域名。要逐字核对完整主机名，不能只看前面的字。

这里只做本地结构检查，没有联网查毒，也不读取你的剪贴板。你点击粘贴后才会处理内容。

先读二维码，不直接跳转

选一张带普通二维码的截图。显示里面的文本或网址，识别后不会打开链接，不需要相机权限。

JPG / PNG / WebP，最多 10 MiB。建议先裁出一个清晰完整的二维码，保留四周白边。小程序码、条形码不支持。

付款信息、Wi-Fi 密码、名片等也可能编码在里面。复制或分享前请自行确认；工具不验证收款人或内容真伪。

本机识别，文件不上传

二维码识别使用本页托管的 jsQR，没有第三方扫码服务。

若无法识别，尝试在相册裁切、调整方向，保留白边后重选。彩色艺术码、严重模糊或遮挡的码可能识别不了。

微信内置浏览器如不能选文件，可用系统浏览器打开。结果只留在本页内存。

查商家，先对主体

分清“代码写对了”和“公司真实、正在经营”。这里只检查代码字符与校验位；登记、备案及经营情况，到官方渠道查。

可识别小写、空格和全角字符。不要输入个人身份证号码。

国家企业信用信息公示系统 ↗手动输入企业名称或代码，核对登记与经营异常工信部 ICP 备案查询 ↗手动输入网站域名，对照备案主体

打开官方站点不会自动携带你输入的代码。可能需要验证码、登录，或暂时不可用。备案和登记都不等于业务安全保证。

核验时对这三件事

  1. 商家说的公司全称，与登记名称是否一致。
  2. 付款页主体、合同抬头，与核实的经营主体是否匹配。
  3. 对方催促、冒充客服或索要验证码时，通过自己找到的官方渠道确认。

遇到正在发生的紧急诈骗风险，先停止付款；必要时联系银行和警方。这里不代查个人身份或资金。

补充：中文公开线索搜索

用品牌、公司全称或公开昵称构造搜索词。点击后才会把搜索词交给对应搜索引擎，不会自动查账号或返回“命中”。

不要用手机号、身份证、邮箱或私密信息查人。搜索结果需核对原文与时间，同名不代表同一人。

LOCAL FILE / EXIFR + SHA-256

先读文件，不把文件发出去。

计算任意文件的 SHA-256；用 exifr 读取 JPEG / TIFF 照片中的相机、拍摄时间等字段。原文件不会被修改。

▧单个文件最大 25 MiB，所有处理在本页完成。

位置可能暴露住址或活动地点，默认隐藏，不自动打开地图。

细节，不等于证明。

相同 SHA-256 可用于比对文件是否一致，不能证明内容真实或来源可靠。

EXIF 可被编辑、删除；社交平台通常会移除部分字段。没有元数据，不代表照片有问题。

文件和结果只在当前页面内存中，刷新即清空。网页不把它们写入本地存储或发送给服务器。

中文昵称 / 公开搜索 / SHERLOCK

用中文昵称，查大陆常用平台

输入公开昵称，准备各平台的搜索入口。点击后由平台显示候选结果；不会自动查号，也不把同名账号认作同一人。

大陆模式支持 1–64 个字符的中文、英文、数字和常用昵称符号。国际模式仍限英文用户名格式。请勿输入手机号、证件、邮箱或私密信息。

Sherlock 命令助手 · 仅国际用户名模式在你自己的电脑运行
中文昵称搜索无需运行命令。切换国际用户名模式后可生成 Sherlock 命令。

安装：pipx install sherlock-project。运行后会访问第三方站点；请仅核查自己的账号或已获授权的对象，并遵守各站规则。
